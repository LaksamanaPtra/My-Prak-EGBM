# Praktikum EGBM (Electrical, Gravity, Magnetic Methods Practicum)

Scripts and processing outputs from the EGBM practicum (Semester 3).

| Folder | Description |
|---|---|
| `Akuisisi-Magnetik-Geodetik/` | Generators for magnetic and geodetic acquisition: station coordinates, KML export, field forms, base-station processing |
| `Kulap-Desain-Akuisisi/` | Field-camp gravity acquisition design: DEMNAS processing, terrain-correction (TC) rebuild, QGIS map layouts |
| `Laporan-ETS-Peta-TMI/` | Total Magnetic Intensity (TMI) map scripts for the midterm report (base-rover and rover-rover), with gridding logs and statistics |
| `W7-FFT-2D/` | 2D FFT demo on checkerboards and photos |

Some acquisition-design scripts were made for group fieldwork.

---
Coursework, Geophysical Engineering, Institut Teknologi Sepuluh Nopember (ITS).
Raw data files larger than 10 MB, QGIS project files, rasters, and report documents (PDF/DOCX/PPTX) are kept offline and not included.
